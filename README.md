# LDROBOT D500 — радар комнаты

Живой мониторинг комнаты с 2D-лидара LDROBOT D500 (он же STL-19P): не просто
контур стен, а детекция и трекинг людей, тепловая карта присутствия и охранные
зоны со звуковой тревогой — всё в браузере в реальном времени.

## Железо
LDROBOT D500 (STL-19P), подключение по COM-порту (USB-плата CP210x), 230400 бод,
360°, дальность до 12 м, 10 Гц. Данные односторонние — лидар только отдаёт кадры.

## Компоненты
- `ld_lidar.py` — парсер протокола (кадр 47 байт, CRC8) и фоновый читатель `LidarReader`
  с автопоиском и переподключением порта.
- `analytics.py` — движок: обучение фона (стены), выделение движущихся точек,
  кластеризация, трекинг с ID/скоростью/траекторией, метрики комнаты.
- `server.py` — веб-сервер (HTTP 8080 + WebSocket 8081), стримит сцену в браузер.
- `web/index.html` — дашборд: радар, треки, зоны, тепловая карта, экспорт плана.
- `view3d.py` / `view2d.py` — десктопные вьюверы (Open3D и matplotlib).
- `probe.py` — автоопределение скорости порта. `tools/monitor_ws.py` — лог-анализатор потока.

## Возможности
Трекинг людей и объектов (человек отличается от предмета по ширине кластера),
счётчик людей, размеры комнаты, тепловая карта присутствия, охранные зоны с
подсветкой и звуковой тревогой при входе.

## Запуск
```
python server.py COM9
```
Открыть http://localhost:8080 (с телефона — адрес из той же Wi-Fi, который печатает сервер).
Первые секунды лидар учит фон комнаты — стойте в стороне, затем заходите в кадр.
COM-порт на Windows эксклюзивный: десктопные вьюверы запускайте при остановленном сервере.
